AI proposes.
Evidence decides.
A person approves.

ASTraCAD Ω is a self-auditing decision engine for engineering inspection plans. It does not only ask whether a source supports a claim. It asks whether the part supports it — and when two sources disagree, it refuses to average them.

Open the live decision record → Source on GitHub

What the record shows

  1. A ruling, not a scoreEach characteristic resolves to ACCEPT, HOLD, REJECT or NOT_JUDGEABLE, with the reason written next to it — including "no definite limits, so a measurement could be recorded but never judged".
  2. Two sources, one arbitrationWhen the drawing and an independent parse disagree, the decision is HOLD and a human arbitrates. Nothing is silently merged; the disagreement is the output.
  3. Confidence from the weakest linkThe record's confidence floor is the weakest fact, not the average of the strong ones. One unsupported premise drags the whole decision down.
  4. What is missing is reported missingMissing limits, missing revision, missing calibration — absence is a first-class finding, never blank space.
  5. A chain that fails when tamperedEvery fact carries a SHA-256 provenance hash in an append-only log; edit a line and the verifier exits non-zero.

Why this is not a wrapper around a model

A model may propose; it may never approve

Model output enters as AI_PROPOSED. The states that carry weight — EXTRACTED, CALCULATED, VERIFIED, HUMAN_APPROVED — are written by evidence and people, not by the model.

Two people to release

A release is a signed act under a two-person rule. The engine records who stated it, when, and on what evidence — and refuses the ruling when the evidence is not there.

It learns which source lied last time

Each source's weight is a calibrated Beta posterior over recorded outcomes. It stays at its stated prior until five outcomes exist, and three per kind — the engine will not pretend to be calibrated on n=1.

Refusal is a designed outcome

A broken chain exits 4. An unsupported release exits 2. The failure modes are enumerated and tested, not discovered in production.

Run it yourself

git clone https://github.com/osmiumuas-wq/astracad && cd astracad
set PYTHONPATH=src        # PowerShell: $env:PYTHONPATH="src"
py tools/decide_demo.py examples/acad.plan.json
start _out/decide_demo/index.html

Python 3.14, standard library only — no pip install, no model API key, no network. The page above is the exact artefact that command writes.

Honest limits

Stated plainly, because a judge should not have to find them:

  • The five outcomes visible in the record are a rehearsal — labelled as such on the page — made to show the learning loop move, not measurements of a real part.
  • The repository is a prototype: verified end-to-end on synthetic drawings and a SOLIDWORKS corpus, not on a production drawing office.
  • The Windows COM path to SOLIDWORKS is kept off the judged path; the decision engine runs with no CAD application installed.
  • Nothing here claims a win, a benchmark crown or a client. It claims a traceable ruling, and it shows its work.
